# Tachyogenesis
 
*Athena wakes up in the distant future with retrograde amnesia and a time-manipulating gauntlet that doesn't quite work. Join her on her quest to save the universe from its temporal demise and to remember who she once was.*

## Keybindings
*One will be able to change keybindings in the earliest release version at the latest*

- `A/D | Left Arrow/Right Arrow` Move left / right
- `W/Up Arrow` - Jump
- `E/Enter` - Interact
- `Q` - Exit / Fast-Forward Dialogue

### From the Releases

1. Check out the [Latest Release](https://github.com/theinfamousben/tachyogenesis/releases/tag/p0.1)
2. Download the .zip file for your operating system.
3. Extract the files into another folder.
4. Run the executable (`.exe` for windows, `.sh` for linux)

### From Itch.io

### Build from Source
1. Clone the repository  
```bash 
git clone https://github.com/theinfamousben/tachyogenesis.git
```
2. Open the Project in Godot 4.7 Mono
3. Click Export
4. Export to your desired Operating System (you may need to add the export preset first.)
